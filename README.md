# MyTube

יוטיוב אישי לאנדרואיד. הריפו הזה מכיל רק גרסאות מוכנות להתקנה.

## הורדה

**[הגרסה האחרונה](https://github.com/etamarsar/mytube-releases/releases/latest)** – פתח בטלפון ולחץ על הקובץ `MyTube-x.y.apk` תחת Assets.

## התקנה

1. פתח את הקובץ שהורדת.
2. אם אנדרואיד מבקש, אשר התקנה מאפליקציות לא מוכרות לדפדפן.
3. לחץ "התקן".

מרגע ההתקנה האפליקציה מתעדכנת לבד: בכל פתיחה היא בודקת אם יש כאן גרסה חדשה, מורידה ומציעה להתקין.

## התחברות עם Google

אופציונלית (מנויים, לייקים, פלייליסטים, סנכרון). כל עוד האפליקציה במצב בדיקה בגוגל יופיע מסך "אפליקציה לא מאומתת": לחץ "מתקדם" ואז "המשך".
